# Twitter 詳細検索URL生成ツール

Twitter（X）の詳細検索URLをフォームから簡単に生成するツール。GitHub Pagesでホスト。

## 機能

- **キーワード**: AND / 完全一致 / OR / 除外 / ハッシュタグ
- **アカウント**: 送信者 (from) / 受信者 (to) / メンション
- **期間**: プリセット（今日・1週間・1ヶ月）＋日付ピッカー
- **言語フィルタ**: 日本語・英語・中国語など9言語
- **メディア**: 画像 / 動画
- **返信**: 返信を含める / 返信のみ表示
- **リンク**: リンク付きを含める / リンク付きのみ表示
- **エンゲージメント（最小値）**: 返信数 / いいね数 / リポスト数
- 生成URLをリアルタイムプレビュー
- クリップボードコピー＋X（Twitter）で直接開く
- 検索条件をURLクエリパラメータで保存・共有

## 技術スタック

- HTML + CSS + JavaScript（ビルドなし、外部依存なし）
- GitHub Pages でホスト

## デプロイ

```bash
git push origin main
```

GitHub Pages の設定で `main` ブランチのルートを公開元に設定する。
